# Akkini Rathangal Prayer Fellowship – Bible Reading Tracker (MERN)

## Run locally
1. Install Node 18+ and MongoDB (or a free MongoDB Atlas URI).
2. `cd server && cp .env.example .env` (edit MONGODB_URI, JWT_SECRET) `&& npm install && npm run dev`
3. In another terminal: `cd client && npm install && npm run dev` → open http://localhost:5173

## Deploy (one service, e.g. Render)
- Build command: `npm run build`   Start command: `npm start`
- Env vars: MONGODB_URI (Atlas), JWT_SECRET
